## Независимое ревью ветки

Два ревьюера прочитали дифф (бэкенд и фронтенд) без запусков. Найденное
исправлено отдельными коммитами:

- `bf3db7a` — проверка F05 в потоке отвергала законные ответы: делитель режет
  первую фразу по запятой, и «Ваши 86 — нереально,» судилось раньше «могу 95».
  Теперь сомнительное придерживается до конца реплики, отвергнутое не звучит
  никогда; признаки сделки и обещания сужены; при заключённой сделке промпт
  называет сделку; перебивание не пишет отвергнутую реплику в журнал; HEAD на
  адреса API снова 405; вердикты с клиента проверяются строже.
- `e9e56ef` — «А что если» сопоставляло ходы по ленте клиента, а записи — по
  журналу сервера (голосом лента может нести лишнюю реплику): запись хода
  несёт реплику и ответ. Офлайн-расчёт для партии с судьёй не показывается.
  WCAG 2.5.3 для кнопок проверки, строгий разбор чисел в TS, кэш портретов
  при обновлении SW, стёртый в другой вкладке профиль.
