## Сборка PPTX за десять минут


1. Открыть оригинальный `tmp/lct-presentation-template.pptx`, сохранить копию. Оставить обязательные слайды 7–11, затем добавить пять содержательных слайдов из макетов 12–29. Удалить вводные инструкции и неиспользуемые макеты.
2. Вставить текст по порядку ниже: наши слайды 1–5 соответствуют шаблону 7–11. На слайде команды оставить два блока.
3. На титуле использовать оригинальный логотип «Алабуга» из слайда 6. В шаблоне оставить Montserrat; PDF/HTML используют доступный Arial.
4. Для слайда 6 вставить `assets/debrief.png`. Для таблицы слайда 7 использовать обычную таблицу PowerPoint.
5. Проверить отмеченные неизвестные сведения, затем сохранить PPTX. Роли: оба участника имеют нейтральное обозначение «Участник команды»; это предложение на утверждение.


Не заполнено владельцем: зарегистрированное название команды, капитан, город/регион, место работы/учёбы, телефоны, история знакомства. В слайдах это отмечено прямо. Личную мотивацию не подменять продуктовой гипотезой.

React / TypeScript, WebSocket и FastAPI. Сценарий хранит роли, скрытые интересы и границы сделки.

Следующий шаг: пилот с наставником и согласованной рубрикой. Организационная лицензия — гипотеза для проверки.


**Заметки докладчика / источники:** Настройки организатора встроены в «Свою ситуацию». Отдельного кабинета с ролями пока нет. Платёжеспособный спрос, эффект обучения и бизнес-модель ещё не подтверждены исследованием. Источники: docs/submission.md, frontend/src/App.tsx, app/realtime/endpoint.py.
