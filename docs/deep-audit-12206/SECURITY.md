# Границы доверия — 26 сентября

Это аудит найденных механизмов, не заявление об отсутствии всех уязвимостей.

| Действие | Фактическое поведение | Доказательство / граница |
|---|---|---|
| Подменить клиентом балл/режим для выдачи | Выдача использует серверную попытку и оценку движка; практика не повышается до экзамена через resume | `tests/test_attestation.py`, полный backend-прогон 25 сентября; API/WS, не DOM |
| Изменить подписанную запись в SQLite | Проверка отказывает | Параметризованный тест меняет overall/grade/id; ожидает 503 без valid |
| Повторно выдать документ | Один документ на попытку, включая конкурентные обращения | Тест идемпотентности и конкурентной выдачи; серверный слой |
| Открыть чужой действующий ID свидетельства | Публичная проверка анонимного результата; личность предъявителя не устанавливается | `attestation.lookup`, endpoint документа, пояснение ServerCertificate и printable HTML |
| Восстановить попытку по известному чужому session ID | Сессия восстанавливается, старое соединение вытесняется | `app/realtime/endpoint.py::_build_session`, `_evict_owner`; `tests/test_takeover_and_limits.py`. ID является секретом доступа к анонимной попытке; индивидуальной авторизации нет |
| Указать неизвестный/истёкший session ID | Создаётся новая попытка | Ветка после store.claim в `_build_session`. Точный пользовательский маршрут истечения в новом DOM-прогоне пока не проверен |
| Реестр недоступен / HTTP-ошибка / неверный JSON / valid=false | Интерфейс не показывает документ как проверенный | `e2e/attestation-passive.mjs`, 4 исхода × RU/EN прошли 25 сентября |
| Заменить HMAC-ключ | Старые записи перестают проходить проверку | Серверный тест; долг версионирования ключа, не исправлялся скрытно |

Не обещать индивидуальную защиту попыток или именной диплом. Общий пароль установки,
если включён, не является отдельной учётной записью участника. Идентификаторы активных
сессий нельзя публиковать как обычные ссылки.

Для режима с сотрудниками нужны идентификация и привязка доступа к попытке.
Добавлять их поверх текущего восстановления без проекта миграции рискованно:
можно сломать reconnect. Решение оставлено владельцу, анонимная семантика сохранена.

Тексты интерфейса проверены по коду: локальная печатная отметка прямо названа учебным
результатом, серверная — анонимной попыткой, квалификация и личность не удостоверены.
Это не подтверждает правомочность будущей выдачи дипломов.
