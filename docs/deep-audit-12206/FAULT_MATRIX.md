# Отказы: доказательства и применимость

26 сентября. «Проверено» относится к указанной поверхности, конфигурации и шагам.
358 основных маршрутов используют общие компоненты, но это не основание объявлять
все 5012 сочетаний проверенными. Неприменимость отделена от отсутствия проверки.

| Категория | Где подтверждено | Что осталось / неприменимость |
|---|---|---|
| Пустой ввод | Каждый основной текстовый стол RU/EN, своя ситуация; кнопка отправки/генерации недоступна | Для чтения/choice/match свободного текстового ввода нет; пустой числовой/свободный ответ курса имеет отдельные компонентные тесты, не каждую DOM-ветку |
| Длинный ввод | Все основные столы: ограничение2000; supplier RU/EN: отправка10000→2000→завершение | Не все числовые/свободные задания курса через DOM |
| Unicode/спецсимволы | Supplier RU/EN: граница суррогатной пары, emoji, HTML/script как буквальный текст; завершение | Все сочетания ZWJ/комбинируемых знаков не проверены; графемную сегментацию не обещаем |
| Двойное нажатие | Supplier RU/EN: одна принятая реплика при dblclick; протокольные тесты idempotency | Двойное нажатие каждой кнопки всех экранов не выполнено |
| Reload | Посреди хода RU/EN: предупреждение, незавершённая попытка не считается законченной | Каждая стадия каждого урока/экзамена отдельно не пройдена |
| История назад/вперёд | RU/EN в своём браузере посреди попытки: возвращается выбор тренировки, выдуманного разбора нет | Текущая локальная SPA не ведёт историю каждого внутреннего экрана; у другой линии стенда навигация отличается |
| Две вкладки | Вторая обычная вкладка не наследует чужую ленту; чужой действующий ID документа открывается с явной анонимностью | Параллельное редактирование localStorage-прогресса разных учебных экранов не покрыто всей матрицей |
| Истёкшая сессия | Реальный gateway, отсутствующий resume ID после подтверждённого хода: явное начало новой попытки, старой ленты нет, новая доходит до разбора; RU/EN | Время TTL не выжидалось: использована та же серверная ветка отсутствующего идентификатора |
| Отказ ASR | Предыдущая реальная приёмка остановленного Parakeet и компонентные проверки; новый голосовой проход использует запись | Новая остановка службы на чужой линии не выполнялась. Физический микрофон — HUMAN_ONLY |
| Отказ TTS | Изолированный gateway с отключённым TTS: голосовые пресеты доходят до разбора; транспортные проверки сообщения об отказе | Каждая стадия TTS/каждый внешний провайдер не воспроизведены; слышимость — HUMAN_ONLY |
| Отказ модели | Полный DOM-сценарий на настоящем gateway: намеренное исключение и зависание15с → резерв → разбор | Качество и крайние задержки внешнего провайдера не гарантируются |
| Обрыв сети | Подтверждённый ход → обрыв → сохранение состояния → разбор; постоянный обрыв → экран восстановления. Отдельно первая offline-загрузка production | Обрыв на каждом из104 упражнений отдельно не прогонялся; автономные детерминированные задания не требуют модельного вызова |
| Потолок35с | Браузерный компонентный тест: этапы, обновляемый счётчик, сообщение, выход; историческая приёмка публичной сборки | Новая проверка совмещённой версии невозможна до её создания; не считать проверкой всех маршрутов |
| Потолок12с | Аналогично для разбора, завершения и выхода RU/EN | Не применяется к экрану, который вообще не запрашивает разбор переговоров |
| Реестр/подмена | RU/EN: экзамен→документ, другой профиль, поддельный POST405, неизвестный ID404, неизменность подписи, повтор resume→тот же ID. Асинхронные отказы проверены компонентно | Анонимность намеренная; индивидуальные права не реализованы. Платный/юридический диплом не обещан |

## Граница завершения

Основные18 маршрутов закрываются отдельными доказательствами; эта матрица расширена,
но перечисленные непокрытые автоматизируемые комбинации **остаются непроверенными**.
Они не перенесены в HUMAN_ONLY как якобы невозможные. Массовый повтор по новой
линии стенда сейчас зависит от разрешения совместить ветки (DEPLOY_AUDIT_12206.md).
