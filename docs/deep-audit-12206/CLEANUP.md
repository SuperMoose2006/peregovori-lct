# Исправления и технический долг

## Исправлено

1. **Поздний отказ закрытого транспорта (25 сентября, f703cc1).** Отказ загрузки офлайн-модуля больше не сообщает `lost` после закрытия попытки. Проверены и активный отказ, и закрытая попытка; возвращение дефекта поймано браузерным тестом.
2. **Устаревшее число блоков курса.** RU/EN обещали девять блоков при одиннадцати на карте. Вступление теперь берёт число из каталога; SSR проверяет обе локали и добавление ещё одного блока. Подстановка девяти намеренно роняет тест.
3. **QA-команды в пользовательском вводе.** Из рабочего офлайн-транспорта удалены текстовые `genfail`/`force-gen-error` и URL-параметр, искусственно вызывавшие отказ. Они ломали допустимые описания ситуаций в доступном пользователю режиме. Три протокольных теста ловят возвращение команд; полный DOM-путь своей ситуации RU/EN с этими словами и параметром прошёл.

4. **Обрезка UTF-16 на границе поля.** Ограничение длины могло оставить половину суррогатной пары. `clampInput` убирает оборванную пару, в том числе уже обрезанную нативным полем. Тест падал до исправления и при возвращении старого helper; DOM проверяет граничный эмодзи, длинную отправленную реплику и завершение партии. Это не обещание сегментации всех графем Unicode.
5. **Первый офлайн-запуск после потери сети.** Service Worker не кешировал начальные JS/CSS, загруженные до получения контроля. Сборка теперь внедряет список своих ресурсов, включая ленивые экраны, в precache. Неуспешная предзагрузка не маскируется успешной установкой. Активация удаляет только кеши своего пространства имён. Полный production-путь «первое посещение → сеть выключена → reload → партия → разбор» прошёл; удаление списка ресурсов и удаление фильтра чужих кешей отдельно роняют его.
6. **Ложное обещание на последнем блоке.** На снимке экзамена блока 11 было «Следующий блок открыт». Последний блок теперь сообщает только сдачу экзамена; остальные сохраняют сообщение о продвижении. SSR обеих локалей падает на прежней реализации и проверяет оба случая.

7. **Истёкшая попытка выдавалась за восстановленную.** При reconnect с отсутствующим ID сервер создаёт новую попытку; раньше UI показывал только «Связь восстановлена». Транспорт теперь сравнивает ID с предыдущим и явно сообщает о новой попытке и невосстановленном результате. RU/EN: подтверждённый ход → обрыв → отсутствующий ID → предупреждение → новая партия → разбор. Подмена сравнения на `false` роняет оба браузерных теста; обычное восстановление старого ID также повторно прошло.

## Убрано

- Неиспользуемый тип CreatedTransport и устаревшее описание выбора WebSocket.
- Ветка и функция искусственного отказа офлайн-генерации: 22 строки рабочего кода. Ошибки проверяются изолированной подменой провайдера/сети, а не скрытой командой внутри описания ситуации.
- Неоднозначный поиск упражнения только по вопросу в приборе курса: теперь учитываются блок и показанная реплика.
- Поиск кнопки проверки по подстроке заменён точным доступным именем.
- Дублирование переводов вариантов ответа в приборе курса заменено словарём приложения.
- Ожидание первого потокового фрагмента как будто это завершённый ответ исправлено в новых DOM-приборах.

## Оставлено явно

| Место | Ограничение | Почему не заменено ночью |
|---|---|---|
| `mock/customScenario.ts` | Локальная своя ситуация — шаблон с эвристиками, не семантическая генерация моделью | Полезный автономный режим; удаление сломает путь без сервера. Не считать проверкой качества живой генерации |
| `mock/engine.ts` и серверный engine | Две реализации одной механики | Обязательное автономное исполнение и parity-инвариант; объединение требует иной архитектуры, это не лишняя копия для механического удаления |
| Провайдер видео | Интерфейс есть, платный поток не подключён | Нужны выбор, аккаунт, ключ и бюджет владельца |
| Аттестация | Анонимный результат; один HMAC-ключ, нет безопасной ротации | Нужны решения по личности/доступу/хранению, совместимая миграция документов |
| Resume | Известный session ID даёт доступ к анонимной попытке | Привязка к учётной записи меняет восстановление соединения и требует проекта авторизации |
| Карта курса | Учебный блок открывается после сдачи предыдущего **или** 50% его прохождения | Осознанное мягкое продвижение практики. Провал не даёт зачёт и мастерский экзамен. Не переделано в жёсткий запрет без требования владельца |
| Старый smoke | Экранный обход, часть профиля заранее разблокирована | Сохраняет пользу для макетов; не учитывается как доказательство прохождения курса |
| `public/sw.js` | Старые хешированные ресурсы сохраняются в стабильном кеше; нет политики очистки устаревших сборок | Немедленное удаление ломает ленивые импорты уже открытых вкладок. Нужны версионирование и проверка миграции, не случайное удаление всего кеша |
| Vite 5 / esbuild | `npm audit` сообщает high / moderate; предлагаемое автоматикой исправление — major Vite 8 | Сборщик слушает loopback. Не запускать `audit fix --force` без проверки совместимости; конкретные advisory сохранены в `tmp/deep-dependency-audit.json`. Стенд этими данными не обследован |
| Локальная мимика | Амплитудный рот, процедурное моргание и зацикленные клипы | Функциональные тесты не подтверждают субъективное качество речи/лица |

Файлы ревьюера, основной checkout, настройки стенда и чужие службы не менялись.
