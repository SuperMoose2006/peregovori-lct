## Карта и роли

358 основных маршрутов из каталогов: 9 столов × 2 исхода × RU/EN, 6 зеркальных
столов, 2 кампании, 11 блоков, 104 упражнения с мастерскими заданиями, 12 чтений
партий и общие пути. Сводка текущих статусов — [STATUS.md](STATUS.md).
У каждого пути записаны шаги, источник доказательства и 14 отдельных категорий
отказов. Запись «не проверялся» не означает «работает».

- Участник: практика, курс, экзамен, прогресс, локальный профиль, анонимное свидетельство.
- Организатор: параметры своей ситуации в общем интерфейсе; отдельного кабинета с разграничением прав нет.
- Преподаватель: отдельный кабинет не реализован, не отмечен проверенным.
- Посетитель реестра: проверка публичного ID результата; предъявление чужого действующего ID не удостоверяет личность.
- Оператор: конфигурация и общий пароль установки, а не индивидуальная роль участника.

`course.mjs --url http://127.0.0.1:15416 --blocks 11 --master --lang ru --out ../tmp/deep-master-ru`
запускается через `node --import tsx`; для macOS задать `CHROME_PATH` на Chrome.

`services/gateway/tools/rehearsal_gateway.py` на18212 и собственный proxy;
не направлять fault controls на стенд. Вариант `--voice` использует
