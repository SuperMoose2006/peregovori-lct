# Кастинг лиц живого видео (LiveAvatar)

Одно лицо на пятнадцать персонажей — это диктор, а не собеседник. Решение
владельца 19.10: подобрать лица из публичного каталога LiveAvatar (50 человек,
293 варианта; `GET https://api.liveavatar.com/v1/avatars/public`, без ключа)
по внешности под каждого персонажа — пол, возраст, роль, характер.

Таблица ниже — источник правды: `services/gateway/tools/sync_casting.py`
переносит пары «стол → UUID» в `app/avatar/live/casting.json` (раздел
`personas`), тест сверяет их при каждой сборке. Варианты лица выбраны по
характеру: `(Friendly)` — персонажам «на отношениях», `(Serious)` — жёстким,
`(Curious)` — аналитикам; студийные «… in Black Suit» сняты на зелёном фоне,
и шлюз ставит свой фон сам (docs/INTEGRATION_LIVE_VIDEO.md, «Хромакей»).
Варианты «(Portrait)» и «(Fullbody)» не берутся: сцена созвона горизонтальная.
