## Запуск одной командой на этой машине

Из корня worktree, после уже выполненной сборки:

```bash
NEGO_AI=off /Users/pozitiv4500/Goool/lct-gaz-gaz/services/gateway/.venv/bin/python -m uvicorn app.main:app --app-dir services/gateway --host 127.0.0.1 --port 8010
```

живой приёмки остановлен. Чистая установка на другой машине — [инструкция](submission.md).

## Подробности этой репетиции

Регрессия: 2725 backend passed, 159 skipped, 2 предупреждения зависимостей;
444 frontend passed; production build успешен. Три мутации пойманы: отключённое сообщение TTS, исчезнувший текст после
reload и перекрытие шапки предупреждением.
Однокомандный запуск проверен на свободном порту 18210: отдаёт собранный SPA.

В настоящем headless Chrome камера сообщила «камер в системе нет», микрофон —
«доступ не разрешён». Отдельные тесты проверяют, что отказ одного устройства
не выключает второе.

Прибор `node frontend/e2e/rehearsal-passive.mjs` запускает отдельный headless
Chrome и Vite, показывает настоящие Home/Table/Debrief. `--live` требует
локальный gateway на 18208. Test-only мост внедряется Vite-преобразованием;
в production-сборке его нет. Снимки и замеры — `tmp/rehearsal*`, не публикуются.

Обнаружены и исправлены два отказа:
- После обновления страницы незавершённая партия терялась без объяснения.
  Теперь стартовый экран сообщает, что она не восстановлена и не завершена.
  Автоматическое восстановление после reload не реализовано; reconnect сокета
  внутри живой страницы проверен отдельными тестами.
- Пустой/ошибочный синтез молчал. Теперь приходит сообщение о доступном тексте;
  зависший синтез ограничен 15 секундами. Это предел отказа, не обещание задержки
  менее двух секунд для внешнего сервиса.

Отказы модели/потока, reconnect, устройства и молчащий аватар проверяются
отдельными тестами. Это не выдано за единый живой прогон со всеми одновременно
внесёнными сетевыми отказами. Ошибки самого нового прибора (слишком широкий
шаблон преобразования и перехват исходников вместо API) исправлены до успешного
прогона. Сравнение текста ошибки отсутствующего устройства также уточнено по
фактическому сообщению браузера.
