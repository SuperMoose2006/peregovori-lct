# Решения владельца — короткий выбор

26 сентября. Ответить можно номером и одним словом. Цены времени приблизительные,
не обязательство; подписки не куплены, постоянная аттестация не включена.
Старые ответы сохранены в [истории](OWNER_QUESTIONS_HISTORY_12206.md), повторно их не запрашиваю.
