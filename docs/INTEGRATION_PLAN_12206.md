Для SW недостаточно просто перестать удалять старые кеши: стендовый fallback
ищет index.html через глобальный `caches.match` и может выбрать старый HTML.
Предлагается выбирать fallback HTML из текущего CACHE_VERSION, а старые
хешированные assets искать в сохраняемых поколениях. Проверка A→B должна
доказывать одновременно сохранность A и актуальность offline HTML B.
Размер precache измерять на кандидате: локальный dist этого захода около 9,8 МБ
(380 файлов, в том числе 135 медиаклипов около 1,7 МБ), **это не измерение стенда**.
Стендовый writer включает всё dist; один недоступный файл или quota failure
может сорвать целиком addAll. Приёмка должна включать этот отказ.
