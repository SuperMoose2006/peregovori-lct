# probes — приборы цикла «починить → проверить»

Скрипты гоняют настоящий браузер (playwright-core + локальный chromium) против
собранного продукта и **измеряют**, а не показывают картинки. Каждый появился
из-за конкретной ошибки, которую иначе не было видно.

| Прибор | Что меряет | Что нашёл |
|---|---|---|
| `audit.mjs` | контраст на реальном фоне, горизонтальная прокрутка, обрезанный текст, цели нажатия, видимость фокуса при настоящих Tab, имена кнопок, уровни заголовков — на 25 состояниях в 4 режимах | 105 замечаний WCAG, сломанную системную тёмную тему, немую навигацию на телефоне, обрезанный текст на курсе |
| `rtvoice.mjs` | голосовой круг: первая гипотеза, итог, судья, первый звук ответа | что старый конвейер молчал 5 с, а realtime печатает по словам |
| `reconnect.mjs` | обрыв связи под работающей партией | что состояние переживает падение гейтвея |
| `mediacheck.mjs` | микрофон и камера через поддельные устройства | четыре бага, из-за которых слои обещали больше, чем делали |
| `bargein.mjs` | перебивание оппонента | что кнопки не было в режиме «только голос» |

## Как запускать

```bash
# аудит идёт против ОФЛАЙН-сборки: детерминированно и бесплатно
VITE_MOCK=1 npx vite build --outDir dist-mock
(cd dist-mock && python3 -m http.server 5199 --bind 127.0.0.1 &)
node probes/audit.mjs

# остальные — против живого гейтвея на https://127.0.0.1:8443
node probes/rtvoice.mjs
```

Микрофон подделывается флагом chromium `--use-file-for-fake-audio-capture`,
поэтому голосовые приборы не требуют ни звуковой карты, ни человека.

**Прибор может врать, и врал.** Проверка переполнения дважды давала ложные
срабатывания (обычная прокрутка рейла; намеренно обрезанный `sr-only`), а
проверка фокуса — 300 штук, потому что `:focus-visible` не включается от
программного `.focus()`. Прежде чем чинить продукт по показаниям прибора,
стоит убедиться, что прибор прав.
