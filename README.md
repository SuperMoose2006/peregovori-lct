# 🤝 Диалог — Negotiation Skills Simulator

Интерактивный тренажёр деловых переговоров, где **исход зависит от стратегии, формулировок и
аргументов** игрока. Живой диалог с ИИ-оппонентом, у которого есть **скрытые интересы**, **красная
линия** и **характер**. Каждая реплика анализируется в реальном времени; после игры — разбор с
коучингом. Методики: **Гарвардский метод · SPIN · BATNA**. Проект для хакатона ЛЦТ.

## Режимы

| | Режим | Что это |
|---|---|---|
| 🥋 | **Практика** | один сценарий из библиотеки, живые метрики и подсказки |
| 📖 | **Кампания «Восхождение»** | сюжетная арка из 4 актов (junior → фаундер); **репутация переносится** между актами и влияет на стартовое доверие следующего оппонента |
| 🎯 | **Своя сделка** | опишите свою **реальную** ситуацию — ИИ сгенерирует под неё оппонента и зону торга |
| 🏆 | **Экзамен** | без подсказок и метрик во время игры; в конце — **сертификат** с оценкой |

4 базовых сценария: контракт с поставщиком · переговоры о зарплате · конфликт отделов · раунд с инвестором.

## Как это работает

**Главный инвариант:** состояние игры и оценку считает **детерминированный движок** (метрики, ZOPA,
вскрытие интересов, счёт A–F). **ИИ (LangGraph) отвечает только за текст реплик оппонента** — при
ошибке/таймауте берётся шаблонный фолбэк, и продукт полностью играбелен без сети. Это делает тренажёр
**прозрачным, честным и воспроизводимым**.

Оценка: `overall = 0.4·экономика + 0.25·отношения + 0.35·техника`. Принципиальная игра (вскрытие
интересов → объективные критерии → размен) ведёт к грейду **A/B**; давление и грубость → **срыв / F**.

## Архитектура

Разделённые **backend (Python / FastAPI / LangGraph)** и **frontend (React / Vite / TS)**, общение по
модальностно-независимому протоколу «ход» поверх **WebSocket**. Текстовый чат сейчас; голос (STT/TTS) —
будущие адаптеры на краях (ядро протокола всегда текстовое).

```
backend/app/
  engine/      детерминированный движок (порт эталона из legacy-node/, byte-identical)
    techniques.py · engine.py · scenarios.py · campaigns.py
  ai/          LangGraph граф оппонента + ChatModel (claude CLI | Anthropic API) + генерация сценариев
  protocol.py  Pydantic-контракт сообщений · views.py  адаптер engine→протокол
  main.py      FastAPI: WS /ws + REST + раздача собранного SPA
frontend/src/  React: ScenarioPicker · Table(Meters+Chat) · Debrief · CustomSituation · Campaign
legacy-node/   исходный zero-dep прототип — эталон поведения (не деплоится)
```

## Слой ИИ (`NEGO_AI`)

| значение | бэкенд | назначение |
|---|---|---|
| `off` (по умолч.) | шаблонные реплики движка | офлайн, полностью играбельно |
| `cli` | обёртка над `claude` CLI | локальная разработка без API-ключа |
| `api` | `ChatAnthropic` | продакшен (`ANTHROPIC_API_KEY`) |

Переход в прод = смена одной env. Детали изоляции CLI и инварианты — в [CLAUDE.md](CLAUDE.md).

## Быстрый старт

```bash
make install                 # venv + pip + npm install
make backend                 # FastAPI на :8010   (офлайн, мгновенный оппонент)
make frontend                # Vite на :5173 (проксирует на :8010)
make test                    # тесты движка (36 зелёных)

# Локальный ИИ-оппонент через claude CLI (без ключа):
NEGO_AI=cli make backend
# Продакшен через API:
NEGO_AI=api ANTHROPIC_API_KEY=sk-... make backend
```

Собранный фронт также раздаётся самим бэкендом (`cd frontend && npm run build`, затем открыть
`http://localhost:8010/`) — один процесс на весь продукт.
