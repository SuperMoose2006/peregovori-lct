# 🤝 Диалог — тренажёр переговоров

Исход переговоров зависит от стратегии, формулировок и аргументов игрока, а не от
удачи. Оппонент — ИИ с характером, красной линией и тремя скрытыми интересами.

## Что делает продукт

**Партия.** 12 ходов за столом. Каждая реплика разбирается по смыслу: какой приём
применён, куда метит вопрос, что это сделало с доверием, напряжением,
информацией и рычагом. Цена движется в скрытой зоне согласия, интересы
вскрываются только вопросами по существу.

**Курс.** Девять блоков, 37 уроков, 54 упражнения, экзамен в каждом блоке.
Правильный ответ в упражнении обязан быть правильным в игре — банк не написан, а
**доказан** прогоном через настоящий движок.

**Разбор.** Грейд с тремя составляющими, занавес над скрытыми интересами,
ключевые ходы цитатами из вашей же стенограммы и контрфактический реплей: самый
дорогой ход переигрывается на ваших словах.

## На чём это стоит

Три принципа. Из них выводится почти каждое решение в коде.

**1. Считает движок, а не ИИ.** Состояние, движение цены, вскрытие интересов,
счёт и грейд считает детерминированный автомат. ИИ отвечает только за ТЕКСТ.
Один и тот же набор ходов даёт один и тот же результат — иначе разбору нельзя
верить. Без ИИ и без сети продукт полностью играбелен.

**2. Не заявлять того, чего нет.** Признак живого судьи рисуется, только если
судья отработал. Слой, которого нет, честно сообщает «недоступно». Четвёртого
состояния — «выглядит настоящим, а внутри пусто» — не существует.

**3. Оценка сравнима всегда.** Грейд со включёнными слоями (голос, камера,
чтение эмоций) обязан быть сравним с грейдом без них. Значит ни один сигнал слоя
не входит в `score_session`. Иначе сертификат экзамена ничего не значит.

## Архитектура

```
frontend/                React + Vite, порт клиента MiniCPM-o
    │  WS /v1/realtime  ·  WS /ws  ·  REST
services/gateway/        FastAPI :8010 — партия, курс, разбор
    ├─ engine/           ДЕТЕРМИНИРОВАННЫЙ движок — источник истины
    ├─ ai/               только текст, у каждого вызова фолбэк
    ├─ realtime/         шина с владением поколениями, дуплекс
    ├─ perception/       VAD → детектор конца хода → распознавание
    ├─ orchestrator/     ход, судья, синтез речи
    └─ avatar/           presence (состояния); липсинк — у OpenTalking
legacy-node/             первый прототип — эталон поведения
```

Подробная схема вызовов — в [product.md §9](docs/product.md#9-архитектура).
Провенанс заимствованного кода — [upstream-code-map.md](docs/upstream-code-map.md).

## Быстрый старт

```bash
make install          # venv гейтвея + npm
make gateway          # :8010
make frontend         # :5173, проксирует /ws и /v1 на :8010
make test             # бэкенд + фронтенд
```

Ключ кладётся в `services/gateway/.env` (gitignored), не в командную строку:

```
OPENAI_API_KEY=sk-or-...
OPENAI_BASE_URL=https://openrouter.ai/api/v1
```

Без ключа продукт работает офлайн: движок детерминированный, реплики берутся из
шаблонов, курс и разбор считаются полностью.

Для показа: `make preflight` — проверка перед демо одной командой.

## Модели: роль, а не одна на всё

| Роль | Переменная | Дефолт |
|---|---|---|
| Реплики оппонента | `NEGO_MODEL_OPPONENT` | `google/gemini-3.5-flash-lite` |
| Судья каждого хода | `NEGO_MODEL_JUDGE` | `google/gemini-3.5-flash-lite` |
| Зрение | `NEGO_MODEL_VISION` | `google/gemini-3.1-flash-lite` |
| Разбор, генерация сценария | `NEGO_MODEL_REASONING` | `google/gemini-3.5-flash-lite` |
| Распознавание речи | `NEGO_MODEL_ASR` | `google/gemini-3.7-flash` |

Разведены по двум причинам: судья стоит в критическом пути (движок не может
посчитать ход без балла), а реплику оппонента человек слышит вслух. Обоснование
выбора и чем ломались другие модели — [model-bakeoff.md](docs/model-bakeoff.md).

Синтез речи — edge-tts, а не OpenRouter: русский голос важнее идеологической
чистоты «всё через один шлюз».

## Тесты

Тесты **всегда офлайн**: `conftest.py` принудительно ставит `NEGO_AI=off`, поэтому
прогон ничего не стоит и ничего не зовёт по сети.

Что проверяется помимо обычного: паритет текста и голоса разбором AST, паритет
офлайн-ядра с серверным движком, каждый пункт курса прогоном через настоящие
`analyze()`/`apply_move()` на двух языках, и конвенция пометок незавершённого.
