# Макеты UX/UI (Superdesign)

Открывать [`index.html`](index.html) — оглавление со всеми экранами.
Работает локально, **сеть не нужна**.

Соседняя папка [`../immersion/`](../immersion) — артборды Claude Design,
это другая работа.

## Порядок

Нумерация соответствует ходу работы, а не важности.

| # | Экран | В коде |
|---|---|---|
| 01 | Копия «как было» — главная в скине «додзё» | точка отсчёта |
| 02 | Сдержанный вариант: структура Duolingo, палитра додзё | нет, отклонён |
| 03 | **Оболочка — принятый вариант** | да |

| 05 | Подготовка к партии: слои и пресеты | да |
| 06 | Момент вопроса «что с ней сейчас» | да |
| 07 | Разбор ответа на вопрос | да |
| 08 | Голосовой режим | **нарисован, помечен недоступным** |
| 09 | Разбор со слоями-наблюдениями | да |

Про 08: интерфейса без работающего распознавания в продукте не бывает — слой
честно объявляет себя недоступным, пока клиент не подключён к `/v1/realtime`.
Макет нужен, чтобы было что реализовывать, когда дойдут руки.

Вариант 02 содержит **выдуманные данные** — четыре сценария вместо восьми,
несуществующий ранг «Адепт». Смотреть как на композицию, не как на макет.

## Почему страницы правлены

В исходном виде макеты тянут Tailwind, Iconify и шрифты из CDN. Без сети
синхронный `<script>` блокирует парсинг, `<body>` не создаётся, окно остаётся
белым — то есть открыть их на защите без интернета было бы нельзя.

Поэтому: Tailwind заменён локальной копией (`vendor/`), Iconify и веб-шрифты
вырезаны, внешние картинки заменены инлайновыми SVG-заглушками. **Формы, цвета и
раскладка не тронуты.** Проверено рендером с полностью отрезанной сетью: все
десять страниц отрисовываются, внешних запросов ноль.

`manifest.json` — соответствие файла и draft id на канвасе, если понадобится
исходник.
