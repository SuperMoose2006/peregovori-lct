# 🤝 Диалог — Negotiation Skills Simulator

> Интерактивный тренажёр деловых переговоров, где **исход зависит от вашей стратегии, формулировок и аргументов**.
> An interactive business-negotiation simulator where **the outcome depends on your strategy, wording and arguments.**

Разработано для задачи ЛЦТ «Интерактивный тренажёр навыков ведения переговоров».
Каждая ваша реплика анализируется в реальном времени по методам **Гарвардских переговоров**, **SPIN** и **BATNA**.

## 🎯 Концепция / Concept

Большинство тренингов по переговорам — это теория. Здесь вы **практикуетесь в безопасной песочнице**:
ведёте живой диалог с ИИ-оппонентом, у которого есть **скрытые интересы**, **красная линия (reservation
price)** и **характер**. Один и тот же результат можно получить двумя путями — продуктивным (вскрыть интересы
вопросами, опереться на объективные критерии, обменяться уступками) или разрушительным (давление, угрозы).
Движок **вознаграждает первый путь** лучшей сделкой *и* сохранёнными отношениями, и **наказывает второй**
ростом напряжения, который замораживает уступки.

### Ключевые механики / Core mechanics

| Механика | Что моделирует |
|---|---|
| **Позиции vs Интересы** | За стартовой ценой оппонента спрятаны 3 реальных интереса. Вскрыть их можно только вопросами (Harvard: focus on interests). |
| **4 живые метрики** | **Доверие · Напряжение · Информация · Рычаг** реагируют на каждую формулировку. |
| **ZOPA** | Зона возможного соглашения между вашей красной линией и красной линией оппонента. Где именно внутри неё вы сойдётесь — зависит от техники. |
| **Распознавание техник** | Свободный текст разбирается на ходы: SPIN (S/P/I/N), объективные критерии, эмпатия, размен (логроллинг), BATNA, давление. |
| **BATNA как рычаг** | Сильная альтернатива усиливает позицию — но грубо применённая повышает напряжение. |
| **Разбор с коучингом** | Оценка (A–F) по трём осям: экономика сделки, отношения, техника — плюс персональные рекомендации. |

### Сценарии / Scenarios

| # | Сценарий | Тип | Особенность |
|---|---|---|---|
| 📦 | Контракт с поставщиком | цена ↓ | ориентирован на отношения, не любит давление |
| 💼 | Переговоры о зарплате | пакет ↑ | уважает рыночные данные (objective criteria) |
| 🤝 | Конфликт между отделами | эмоции | деньги ни при чём — отделите человека от проблемы |
| 🚀 | Раунд с инвестором | доля ↓ | сильная BATNA как козырь |

## 🧠 Как работает движок / How the engine works

```
Реплика игрока (свободный текст)
        │
        ▼
  techniques.analyze()      ← билингвальный (RU/EN) разбор на ходы + оценка аргументации
        │
        ▼
  engine.applyMove()        ← детерминированный конечный автомат:
        │                      обновляет метрики, двигает оффер внутри ZOPA,
        │                      выбирает реакцию оппонента по его характеру
        ▼
  engine.renderLine()  ──▶  (опц.) llm.js: реплика в характере через Claude
        │
        ▼
  engine.scoreSession()     ← разбор: A–F + коучинг
```

**Почему rule-based, а не «чёрный ящик»:** тренажёр должен быть *прозрачным* и *воспроизводимым* —
каждое распознавание техники можно показать ученику («здесь вы применили объективный критерий»),
а исход одинаков при одинаковых действиях. LLM подключается опционально и отвечает только за
*художественность* реплик; **состояние игры и оценку всегда считает детерминированный движок**.

### Модель оценки / Scoring model

`overall = 0.40 · economic + 0.25 · relationship + 0.35 · technique`

- **economic** — где внутри ZOPA закрылась сделка (0 = ваша красная линия, 100 = ваша цель).
- **relationship** — итог доверия за вычетом напряжения.
- **technique** — разнообразие и уместность приёмов: этапы SPIN, объективные критерии, вскрытые
  интересы, размены, активное слушание; штраф за угрозы и грубость.

## 📁 Структура / Project structure

```
├── server.js              # zero-dependency HTTP server + JSON API
├── engine/
│   ├── techniques.js      # bilingual technique classifier + argumentation scoring
│   ├── engine.js          # state machine, opponent AI, scoring & debrief
│   └── llm.js             # OPTIONAL Claude adapter for in-character dialogue
├── data/
│   └── scenarios.js       # scenarios: positions, hidden interests, ZOPA, personas
├── public/                # single-page app (vanilla JS, no build step)
│   ├── index.html · styles.css · app.js · i18n.js
└── test/
    └── engine.test.js     # 14 behavioural invariants
```

## 🔌 API

| Method | Endpoint | Назначение |
|---|---|---|
| `GET`  | `/api/scenarios?lang=ru\|en` | список сценариев |
| `POST` | `/api/start` | начать сессию `{scenarioId}` |
| `POST` | `/api/say`   | отправить реплику `{sessionId, text}` → анализ, дельты, ответ, разбор |
| `POST` | `/api/hint`  | контекстная подсказка коуча |
